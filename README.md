## Deploy
1. Upload the files to your repository or static host.
2. If you use Cloudflare Pages, keep the build command empty and output root.
3. Replace `ca-pub-XXXXXXXX` and sample ad slot IDs after AdSense approval.
4. Test the forms once after deployment to confirm browser compatibility.

## Notes
- All calculators run client-side in the browser.
- Currency conversion uses a manual rate, not a live exchange-rate API.
- Employment-related tools are planning estimates, not legal advice.
