# ToolNest starter

## Replace before launch
- example.com with your real domain
- AdSense placeholders with your real ad code
- Privacy Policy and Terms pages with finalized legal text

## Deploy to Cloudflare Pages
1. Create a GitHub repo and upload these files.
2. In Cloudflare Dashboard, go to Workers & Pages > Create > Pages > Connect to Git.
3. Select the repo.
4. Framework preset: None.
5. Build command: leave empty.
6. Build output directory: `/`.
7. Deploy.
8. Add your custom domain in Pages > Custom domains.
9. Update DNS at Namecheap if needed.
10. Submit your sitemap in Google Search Console.

## Fast growth plan
- Keep one tool per folder.
- Use the same template.
- Add 2-3 FAQs per tool page.
- Add 300-800 words of unique explanation under each tool.

## AdSense placement
- one top banner on homepage
- one ad below each tool result
- one ad near FAQ content on long pages
