How this tool works

This page now generates real random passwords in the browser instead of only estimating possible combinations. You can choose the character groups you want, control the length, and optionally avoid confusing characters like O, 0, l, and 1.

The strength estimate is a simple guide based on length and the size of the character pool. It is useful for rough comparison, but your exact security depends on where and how the password is used.

Frequently asked questions

Is the password sent anywhere?

No. The generator runs entirely in your browser.

Should I use symbols?

Usually yes, unless a specific site blocks them.

What length is a good default?

For most accounts, 14 to 20 characters is a strong starting point.
